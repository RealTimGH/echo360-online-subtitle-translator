Echo360 Subtitle Translator

为 Echo360 录播课加载翻译字幕。默认配置适合快速试用；如果重视翻译质量，建议在基础设置中切换到 AI/API 模型。

基础设置

关闭时，所有已选服务按当前权重并行翻译。开启后默认只用第一级，字幕总数超过阈值时，后续级别累加加入。
每级可以有一个或多个服务。在下方服务列表选择所属级别。上移／下移交换整组服务，数量阈值保留在对应级别；删除空组前请先调整服务归属。最多 8 级。
阈值按整份字幕的 cue 数计算，同一条内换行仍算一条。仅在“超过”阈值时启用，未达到阈值的服务也不参与故障转移。已启用服务共同按权重分担；失败时优先尝试较高级别。

翻译面板外观

          
          
          
控制 Echo360 页面内翻译面板的配色。"自动"根据操作系统深/浅色偏好自动切换。

        


        

          
一键翻译行为

          
          
开启后，点击右下角一键按钮会自动下载当前课程的 AI 翻译 JSON 材料，并把任务说明复制到剪贴板。关闭后仍会正常翻译字幕；需要 AI 手动翻译材料时，可在面板中打开并手动导出。

        


        

          
首次使用

          
默认选择 Google Translate，因为它免费且无需 API Key，适合首次安装后立即试用；它使用非官方网页端点，稳定性与配额没有保证。打开 Echo360 录播页后，点击右下角 加载翻译字幕。

          
如果你更重视翻译质量，建议改用 DeepSeek、OpenAI、Gemini 或 DeepL，并填写自己的 API Key。字幕文本会发送到你选择的第三方服务进行翻译。

        


        

          
数据与隐私

          
扩展只在 Echo360/Canvas 课程页面运行，用于读取字幕、生成翻译字幕并保存本地配置。

          
    
            
  • API Key 保存在 Chrome 本地 storage，不上传到本项目服务器。
    • 
            
  • 字幕内容会发送到你选择的翻译服务。
    • 
            
  • 本地缓存只保留最近的翻译字幕，用于刷新页面后快速加载。
